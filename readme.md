> **Overview**
> Welcoming Message handles user onboarding for Discord servers. It greets new members and assigns initial roles seamlessly, using a lightweight Node.js architecture.

<br>

### ✦ Features
- **Auto-Greeting:** Welcomes new members instantly.
- **Role Assignment:** Automatically gives starting roles.
- **Minimalist Codebase:** Easy to tweak and deploy.

<br>

### ✦ Quick Start

```bash
git clone https://github.com/TheoPerson/Welcoming-Message.git
cd Welcoming-Message
npm install
node index.js
```
